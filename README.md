# Uccelli d'Italia · Studio e riconoscimento

PWA didattica con:
- 100 specie per lo studio e il riconoscimento visivo
- 50 specie con canti/richiami
- 64 registrazioni audio
- modalità Studio, Riconoscimento visivo, Canti e richiami
- progressi salvati localmente nel browser
- funzionamento offline dopo il primo caricamento

Ideata e curata da **prof. Flavio Naretti**.

## Pubblicazione GitHub Pages
Pubblicare dalla branch `main`, cartella `/ (root)`.

## Installazione
- iPhone/iPad: aprire il sito in Safari → Condividi → Aggiungi alla schermata Home.
- Android: aprire il sito nel browser → Installa app / Aggiungi alla schermata Home (la voce può variare in base al browser).
